A cut-out object (part of a product, a ball, a net, the shield) floating over sections, frames and headlines with a soft, realistic shadow. `<FloatingCutout src alt width rotate temp />` or with children (for example `StampedShield`). The only place a shadow is allowed: physical objects. `temp` adds a "Temporary photo" tag for cut-outs from the current product photos. Needs a transparent PNG; for photos on white use `mix-blend-mode:multiply` over the colour block instead.
