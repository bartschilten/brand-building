Large, quiet lines of a playing field (A), cut off by the edge, as a section or card background. `<FieldLines type="football" />` with `type` one of `football` (goals), `basketball` (poles), `trampoline` (trampolines), `track` (general), `goal` (goal with net: goal walls, rebounders). The colour comes from `currentColor` (or the `color` prop): `brand` on `ink` for dark sections, `stuntpark-grey` on `surface` for light ones; any palette colour that fits the section is allowed. `opacity` (0 to 1) lowers the contrast; `fit="meet"` shows the whole drawing instead of cropping it. The parent provides the size (the SVG fills it). Decorative only: hidden from screen readers, never behind small text.
