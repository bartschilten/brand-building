The BLITS shield as stamped, brushed metal (D2). `<StampedShield size={96} />`, `orientation="landscape"` for the landscape shield. Uses the supplied logo as a mask, so the shape is never redrawn. Only on a dark field (`ink` or `night-pitch-green`). The consumer may pass `src` (a logo file) when the site hosts its own copies; otherwise the design system's upload is used. `label` sets the accessible name (default "BLITS").
