A form field as a flat plate: the same stepped corners as the cards, a small uppercase label, the input in the display face (uppercase italic, 22px, so no zoom on phones) on a dashed writing line, like a pitch line. `<Field label placeholder name type autoComplete>{optional Button}</Field>`. On focus the dashed line turns into a solid `marathon-blue` line (the focus indicator, 3.7:1 on concrete grey; the plate clips a normal outline). A button passed as child sits beside the plate, full width under it on a phone. Works on `surface-warm` and `surface`; on a dark section the plate stays concrete grey. Used for the dealer search on Home and the dealer application form.
