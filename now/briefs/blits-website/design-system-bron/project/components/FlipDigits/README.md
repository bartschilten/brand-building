Flip digits from an old scoreboard (G2), for **real product facts only** (size, number of products, warranty), never for winning or ranking. `<FlipDigits value="500×200" unit="cm" label="Largest goal" />`. Digits count up from a dash to their value once, when they scroll into view (each flip 70 ms, ease-out, transform and opacity only; a 0 is a single flip); `animate={false}` shows them still. Separators such as `×` and `Ø` sit between tiles without a tile. `size="sm"` for a smaller row. Screen readers get the plain value and unit. Placeholders such as `[000.000]` render as dashed tiles of the same size, so the layout does not jump when the real figure arrives; screen readers hear "To be confirmed".
