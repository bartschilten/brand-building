Flip digits from an old scoreboard (G2), for **real product facts only** (size, number of products, warranty), never for winning or ranking. `<FlipDigits value="500×200" unit="cm" label="Largest goal" />`. Digits flip through to their value once, when they scroll into view (each flip 70 ms, ease-out, transform and opacity only); `animate={false}` shows them still. Separators such as `×` and `Ø` sit between tiles without a tile. `size="sm"` for a smaller row. Screen readers get the plain value and unit. Placeholders such as `[00]` are allowed and must stay visible until the real figure exists.
