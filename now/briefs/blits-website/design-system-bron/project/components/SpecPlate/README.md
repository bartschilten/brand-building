A brushed aluminium name plate for product facts: size, material, norm, warranty. Only put real facts on it (invented plate data is forbidden). The consumer provides `title`, optional `logo` (a BLITS shield URL, night pitch green) and `rows` of `{label, value}`. Placeholders such as `[NORM]` are allowed until the data exists. It is the only textured element in the system: brushed grain, engraved text, four screw heads and a stamped frame line, built from the `aluminium-*` tokens. Engraved text on the plate is `aluminium-engrave` (6.6:1 or more).
