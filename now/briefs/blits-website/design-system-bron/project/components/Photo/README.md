An image slot with a fixed aspect ratio (`ratio`, default `4 / 5`), the image separate from any text so files can be swapped later. `<Photo src alt ratio cut />`; `cut` adds the stepped corners of the plates. Without `src` it shows a visible placeholder: `kind` (eyebrow, default "Campaign photo") and `brief`, a one-line description of the shot so whoever makes the photo knows what is needed. Campaign photos on Home and Brand only; lifestyle and packshots on product pages.
