Real material photographs (F1 to F7, by Bart) as a section or panel background: `concrete`, `asphalt`, `sand`, `grass`, `mud`, `tartan`, `puddle`. `<Texture material="asphalt" shade={0.35}>…</Texture>`. A `night-pitch-green` shade sits over the photo (`shade` 0 to 1, default 0.55; `false` for none) so content on top keeps its contrast. Rules: at most one material per section, never directly behind running text (use it behind a panel, a chalk drawing or a short display line), material colours are not brand colours. Sites that host their own copies call `Blits.configureAssets({textures:{asphalt:"..."}})` once.
