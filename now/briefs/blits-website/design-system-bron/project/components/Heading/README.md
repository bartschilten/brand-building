Uppercase italic headline in the display face with an optional outline accent word. The consumer provides the text and chooses the level and size (`xl` hero, `l` page, `m` section, `s` small). Use one accent word per headline at most, in `action` (red, default) or `brand` (green). Keep line-height at 1 em; never add a second accent word. The accent is a stroke over a fill in the section background (`--accent-fill`, default `surface`): set it on sections with another background. Do not use it for body copy.
